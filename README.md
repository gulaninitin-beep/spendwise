## Project Overview

SpendWise is a personal expense tracker that helps users record daily expenses, manage a monthly budget, and understand their spending habits through a category-wise spending breakdown.

Users can add, edit, and delete expenses, view monthly transactions, monitor their remaining budget, and export expense records as a CSV file.

## Implemented Features

- [x] Add expenses with custom names, amounts, categories, and dates
- [x] View monthly expenses and total spending
- [x] Set and monitor a monthly budget
- [x] Track remaining budget and budget usage
- [x] View a category-wise spending breakdown
- [x] View today's expenses and recent transactions
- [x] Edit and delete expense records
- [x] Export expense records to CSV
- [x] Email and password authentication
- [x] Supabase integration for authentication and data storage
- [x] Responsive dashboard interface

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/gulaninitin-beep/spendwise.git
   ```

2. Navigate into the project directory:

   ```bash
   cd spendwise
   ```

3. Start a local web server:

   ```bash
   python -m http.server 3000
   ```

4. Open http://localhost:3000 in your browser.

**Note:** The application requires a valid Supabase configuration and appropriate authentication and database permissions.
